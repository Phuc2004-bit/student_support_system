# Application icon

`app_icon.png` and `app_icon.ico` are original, project-owned generated assets
created for Student Support System V1.2 branding preparation. The mark combines
an open book with a progress/check symbol and does not incorporate a third-party
logo or trademark.

The PNG is the transparent 1024×1024 master. The Windows ICO contains dedicated
entries at 16, 24, 32, 48, 64, 128, and 256 pixels.
