STUDENT SUPPORT SYSTEM V1.1
===========================

YÊU CẦU HỆ THỐNG

- Windows 64-bit.
- Microsoft SQL Server hoặc SQL Server Express.
- Database production student_support_db đã được tạo đúng schema.
- Microsoft ODBC Driver 18 for SQL Server.
- Windows user đang đăng nhập có quyền truy cập database.

CẤU HÌNH

1. Sao chép file .env.example thành .env trong cùng thư mục với
   StudentSupportSystem.exe.
2. Chỉnh DB_SERVER và DB_NAME theo môi trường triển khai.
3. Giữ Windows Authentication bằng DB_TRUSTED_CONNECTION=yes.
4. Không ghi mật khẩu hoặc thông tin bí mật vào file được chia sẻ.

CHẠY ỨNG DỤNG

Chạy StudentSupportSystem.exe và đăng nhập bằng tài khoản được quản trị viên
cấp. SQL Server và ODBC Driver là phần mềm bắt buộc cài riêng, không nằm trong
ứng dụng.

TẠO TÀI KHOẢN ADMIN ĐẦU TIÊN

Bản phát hành nhị phân không kèm Python hoặc source nên người dùng cuối không thể
chạy script bootstrap từ thư mục ứng dụng. Trong bước triển khai ban đầu, người
triển khai phải cấu hình .env trong một source checkout được bảo vệ rồi chạy:

python scripts/create_initial_admin.py

Script hiển thị rõ database đang dùng, yêu cầu nhập mật khẩu ẩn và chỉ tạo tài
khoản khi database chưa có ADMIN đang hoạt động. Không chia sẻ source checkout,
.env hoặc thông tin đăng nhập với người dùng cuối. Ứng dụng không có đăng ký công
khai; sau bootstrap, ADMIN quản lý các tài khoản tiếp theo trong ứng dụng.

NHẬT KÝ

File nhật ký nằm tại:
%LOCALAPPDATA%\StudentSupportSystem\logs\app.log

Khi không thể kết nối, kiểm tra SQL Server service, instance, database, quyền
Windows user và ODBC Driver 18 trước khi liên hệ quản trị hệ thống.
